## Simulation & Numerical Methods

| Project | Description | Stack |
|---------|-------------|-------|
| [2D Ising Model — Monte Carlo](https://github.com/Eran-Rehani/2D-Ising-Model-Monte-Carlo) | Heat-bath (Glauber) dynamics with Numba JIT; recovers the Onsager critical temperature and the exponents β, γ, ν by finite-size scaling | Python · Numba |
| [Hard-Disk Gas — Molecular Dynamics](https://github.com/Eran-Rehani/Hard-Disk-Gas-Molecular-Dynamics) | Exact event-driven MD for a 2D hard-disk gas; verifies Maxwell–Boltzmann and g(r) | Python · NumPy |
| [Numerical Schrödinger Solver](https://github.com/Eran-Rehani/Numerical-Schrodinger-Solver) | Finite differences and Numerov O(h⁴); convergence against the analytic hydrogen spectrum, Coulomb corrections, SCF for multi-electron atoms | Python · SciPy |
| [Computational Physics (77315)](https://github.com/Eran-Rehani/Computational-Physics-77315) | Floating-point stability, interpolation, integration and root-finding, applied to white dwarf structure | Python · Jupyter |
| [Einstein Solid — Monte Carlo](https://github.com/Eran-Rehani/Einstein-Solid-Monte-Carlo) | Microcanonical MC of two coupled Einstein solids; entropy and temperature from first principles | Python |
| [Capacitor Laplace Solver](https://github.com/Eran-Rehani/capacitor-laplace-solver) | Laplace equation for a parallel-plate capacitor by Gauss–Seidel relaxation in cylindrical coordinates | Python · Numba |
